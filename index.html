TechTix Full-stack developer · Auction marketplace

Zawwed: Auction Marketplace Admin Platform

Zawwed is a Libyan online auction marketplace where sellers list products, buyers bid live, and orders are paid online or cash on delivery and shipped by courier. I worked on the web admin console and the backend that powers it.

Admin console (frontend)

A responsive, bilingual (English/Arabic with full right-to-left support) dashboard with light and dark themes, built to the client's Figma design system. Admins can:

  • Monitor sales and KPIs on a dashboard
  • Manage users, auctions and categories
  • Track courier pickups, deliveries and returns
  • Resolve handover disputes
  • Review payments and penalties
  • Export reports
  • Chat with customers in real time

Backend

A Node.js and Express REST API with PostgreSQL (Prisma), Redis and Socket.IO. It integrates an SMS provider for one-time codes, a courier service for shipment tracking, an online payment gateway, push notifications and S3 media storage.

Highlights

  • Two-step admin sign-in: password, then a 6-digit SMS code, with expiry countdown, resend and attempt limits.
  • Payment breakdown chart comparing cash-on-delivery and online sales across 7-day, 30-day and yearly periods.
  • Fixed chart dates that shifted by a day depending on the server's time zone, verified across several time zones.
  • 600+ automated UI and API tests, plus browser checks on every key screen.
